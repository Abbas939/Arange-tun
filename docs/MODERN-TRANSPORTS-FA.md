# روش‌های جدید و اصلاحات امنیتی فورک

این شاخه نسخهٔ توسعه است. نام فعلی پروژه تا انتخاب نام جدید حفظ شده است.
هر دو سمت باید همین نسخهٔ فورک را اجرا کنند. انتقال یک روش از پروژهٔ مرجع
به معنی سازگاری سیمی با همهٔ نسخه‌های آن پروژه نیست.

Based on BackPack by Amin Mohammadi (AminMGMT)
https://github.com/AminMGMT/BackPack

## روش‌های افزوده‌شده

| کاربرد | روش | وضعیت |
|---|---|---|
| مستقیم، انتقال پورت | TCP همراه Noise | پیش‌فرض امن؛ آزمون انتقال و اتصال مجدد |
| مستقیم، انتقال پورت | WS و WSS همراه Noise | بسته‌بندی استاندارد وب‌سوکت؛ آزمون انتقال |
| مستقیم، انتقال پورت | TCP ساده | فقط برای مسیر مورد اعتماد یا داده‌ای که خودش رمز شده است |
| ریورس | XHTTP روی TLS معتبر | اجرای مدیریت‌شدهٔ Xray؛ آزمون واقعی انتقال با ابزار رسمی |
| ریورس | REALITY همراه Vision | اجرای مدیریت‌شدهٔ Xray؛ آزمون واقعی محلی با ابزار رسمی؛ آزمایش مسیر اینترنت لازم است |
| ریورس | Naive روی HTTP/2 | کلاینت رسمی و سرور sing-box؛ ابزارها جداگانه نصب می‌شوند |

تونل مستقیم این شاخه از نوع انتقال پورت در لایهٔ چهار است؛ تونل لایهٔ سه و
رابط شبکهٔ مجازیِ نسخهٔ جدید پروژهٔ مرجع هنوز منتقل نشده‌اند. روش‌های موجود
مانند WireGuard و خروجی امن SSH حفظ شده‌اند. Hysteria2 و TUIC در این مرحله
به‌عنوان گزینهٔ قابل اجرا اضافه نشده‌اند.

هیچ روشی تضمین عبور از فیلترینگ، نامرئی‌شدن بسته‌ها یا افزایش سرعت ندارد.
آزمون محلی، کارکرد روی مسیر اینترنت ایران و خارج را اثبات نمی‌کند.

## راه‌اندازی مستقیم

دو فایل نمونه را کپی کنید:

```text
config/examples/direct-iran.toml
config/examples/direct-kharej.toml
```

در سمت ایران، نشانی سرور خارج را وارد کنید. توکن نمونه را در هر دو سمت با
یک مقدار تصادفی مشترک جایگزین کنید. پورت نمونه فقط روی رابط محلی باز می‌شود؛
برای دسترسی بیرونی، نشانی گوش‌دادن را آگاهانه تغییر دهید.

```bash
openssl rand -hex 32
sudo arange-tun --import-config direct-iran.toml --name direct-main
```

سمت خارج فایل مربوط به خودش را وارد می‌کند. برای حمل وب‌سوکت، مقدار زیر را
در هر دو فایل یکسان تغییر دهید:

```toml
transport = "wss"
```

در این فورک، روش‌های وب‌سوکت نیز داخل خودشان لایهٔ Noise دارند. با نسخهٔ
قدیمیِ فاقد این بسته‌بندی و رمزنگاری سازگار نیستند. برای گواهی عمومی معتبر،
نام سرور و مسیر گواهی و کلید را مطابق توضیحات نوع تنظیمات وارد کنید.

## راه‌اندازی ریورس جدید

در این حالت سرور ایران گوش می‌دهد و سرور خارج به آن وصل می‌شود. هستهٔ ریورس
فقط روی رابط محلی اجرا می‌شود و ابزار کمکی، پورت عمومی را در اختیار دارد.
دو پورت باید متفاوت باشند. ابزار کمکیِ سرور فقط اجازهٔ دسترسی به همان
پورت محلی ریورس را دارد؛ یک پراکسی عمومی برای مقصدهای دلخواه ایجاد نمی‌شود.

نسخه‌های سازگار و هش آرشیوها در فایل زیر ثبت شده‌اند:

```text
tools/helper-lock.json
```

نصب ابزار موردنیاز، روی هر سروری که به آن نیاز دارد:

```bash
sudo python3 tools/install-helper.py xray
sudo python3 tools/install-helper.py sing-box
sudo python3 tools/install-helper.py naive
```

برای روش اول فقط ابزار اول لازم است؛ برای روش مبتنی بر مرورگر، سمت سرور
ابزار دوم و سمت کلاینت ابزار سوم لازم است. نصب‌کننده فقط فایل اجرایی موردنظر
را پس از تطبیق هش از آرشیو خارج می‌کند؛ آرشیوهای ناشناس را اجرا نمی‌کند.

فایل‌های جفت‌شدهٔ زیر را مطابق نامشان انتخاب کنید:

```text
config/examples/reverse-xhttp-server.toml
config/examples/reverse-xhttp-client.toml
config/examples/reverse-reality-server.toml
config/examples/reverse-reality-client.toml
config/examples/reverse-naive-server.toml
config/examples/reverse-naive-client.toml
```

همهٔ جای‌نگهدارها باید جایگزین شوند: توکن، حساب، شناسه، نام دامنه، مسیر
خصوصی و کلیدها. نام دامنهٔ روش مبتنی بر گواهی باید با گواهی تطابق داشته باشد.
برای گواهی خصوصی، فایل اعتماد را صریحاً در کلاینت تعیین کنید؛ بررسی گواهی
خاموش نمی‌شود. برای REALITY، مقصد پوششی معتبر را خودتان تعیین و آزمایش کنید؛
سرور کلید خصوصی و کلاینت فقط کلید عمومی را دریافت می‌کند.

```bash
sudo arange-tun --import-config reverse-xhttp-server.toml --name reverse-main
sudo arange-tun --import-config edited.toml --name reverse-main --replace-config
```

در پنل، «تونل جدید» و سپس «پیکربندی روش‌های جدید و تونل مستقیم» را انتخاب کنید.
ویرایش روش‌های مدیریت‌شده با فرم ساده مسدود شده تا فیلدهای خاص آن‌ها حذف نشود.
برای ویرایش، فایل کامل را از همین واردکننده با گزینهٔ ویرایش ثبت کنید.
پیش از ویرایش موجود، نسخهٔ پشتیبان گرفته می‌شود.

## تغییرات ناسازگار و مهاجرت

- اتصال SSH اکنون کلید سرور را با اثر انگشت معتبر یا فایل اعتماد بررسی می‌کند.
  اثر انگشت را از کانالی مستقل، مثلاً کنسول شرکت میزبان، دریافت کنید.
  دریافت کلید با اسکن شبکه به‌تنهایی هویت سرور را اثبات نمی‌کند.
- روش TLS موتورهای داخلی frp و Rathole اکنون یک نشست Noise داخل TLS دارد.
  هر دو سمت را با هم ارتقا دهید. اتصال نسخهٔ قدیمی بدون بازگشت ناامن رد می‌شود.
- نصب تازهٔ پنل از HTTPS و رمز تصادفی ۱۲۸ بیتی استفاده می‌کند. نشانی و رمز
  نصب‌های موجود خودکار تغییر نمی‌کنند. HTTPS نصب قبلی را جداگانه فعال کنید.
- به‌روزرسانی از پنل در سرویس مستقلی اجرا می‌شود تا ری‌استارت پنل آن را نکشد.
  شناسهٔ همان کامیت دانلودشده ثبت می‌شود و اجرای هم‌زمان به‌روزرسانی قفل دارد.
- تنظیمات تولیدشده، از جمله رمز SSH و کلید VPN، به‌صورت اتمیک با مجوز ۰۶۰۰
  نوشته می‌شوند. مجوز فایل‌های قدیمی که دوباره ذخیره نشده‌اند باید بازبینی شود.
- بکاپ پیش از دست‌زدن به تنظیمات جاری، از نظر سلامت آرشیو، مسیرها، تعداد
  فایل‌ها و حجم بازشده بررسی می‌شود. نوشتن هر فایل اتمیک است؛ بازیابی همهٔ
  فایل‌ها هنوز یک تراکنش یکپارچه با بازگشت خودکار نیست.
- بکاپ حاوی اسرار است و در این مرحله رمزنگاری درون‌ساخت ندارد؛ آن را خصوصی
  نگه دارید و برای نگهداری بیرونی، جداگانه رمزنگاری کنید.

## آزمون و محدودیت‌ها

آزمون‌های محلی شامل انتقال مستقیم، انتقال ریورس، اتصال مجدد SSH، هویت سرور،
رد اتصال TLS بدون اثبات توکن، اعتبارسنجی آرشیو و انتقال واقعی با ابزار رسمی
Xray بوده است. آزمون کامل لینوکسی، تشخیص رقابت داده، ساخت کامل Packet و
بررسی آسیب‌پذیری‌ها در گردش‌کار زیر تعریف شده‌اند و باید پیش از انتشار عبور کنند:

```text
.github/workflows/ci.yml
```

نسخهٔ بدون وابستگی ضبط بسته برای ساخت و آزمون قابل استفاده است؛ روش Packet
در این ساخت صریحاً خطا می‌دهد. سایر روش‌ها از جمله حامل‌های خام بومی لینوکس
تحت تأثیر این گزینه نیستند.

```bash
CGO_ENABLED=0 go build -tags nopcap -o arange-tun .
CGO_ENABLED=1 go build -o arange-tun .
```

ساخت کامل به کامپایلر C و سرآیندهای libpcap نیاز دارد. محیط اجرای نهایی همچنان
لینوکس و systemd است. ساخت ویندوز برای آزمون‌های توسعه، جایگزین تست روی سرور نیست.
